# Project Skills

This directory acts as the local skill library for the project.

## 1. Taste
- **Repository:** https://github.com/Leonxlnx/taste-skill.git
- **Installed Version / Commit:** `ce26fc25c0e5e8cab638f883de62d9a86ee5e45b`
- **Installation Method:** `npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"`
- **Purpose:** High-quality frontend visual design, anti-generic/anti-slop design, layout, typography, spacing, motion, visual hierarchy, and design direction.
- **When to Use:** Establishing visual taste, typography hierarchy, spacing scale, component layouts, and avoiding generic AI templates.
- **Requirement:** Mandatory for frontend design & visual direction.

  - `animate`

  - `review-animations`
